# 概念库维护指南

## 存储位置

`{CONCEPTS_PATH}/` 下**扁平存放**，无子目录。每个概念一个 `.md` 文件。

## 创建与更新流程（Phase 3.3）

### 1. 扫描概念链接

从论文笔记正文和讨论记录中提取所有 `[[概念名]]` 形式的 wikilink。

### 2. 检查是否存在

对每个概念，用 `find {CONCEPTS_PATH} -name "概念名.md"` 检查是否已有笔记。

### 3. 新概念 — 按模板创建

文件命名：英文名首字母大写、空格保留（如 `Compressed Sparse Attention.md`）。
按 `assets/concept-note-template.md` 模板创建，包含：
- YAML frontmatter（type: concept, aliases）
- `## 定义`：一句话说清核心含义
- `## 核心要点`：2-4 条关键特征，每条讲"为什么重要 + 区别于同类概念"
- `## 被引用`：初始化当前论文的引用记录

### 4. 已有概念 — 追加引用

在已有概念笔记的 `## 被引用` 节末尾追加一行：

```markdown
- [[{来源}{年份}-{方法名}]] — {该论文如何使用/讨论了这个概念}
```

不要覆盖已有的引用记录。

## 命名规范

- **英文概念**：用论文中使用的标准英文名（如 `Flow Matching`、`Compressed Sparse Attention`）
- **中文概念**：如果有广泛接受的中文译名，用中文（如 `持续学习`）
- **缩写**：在 `aliases` 中列出缩写和中文名，如 `aliases: [CSA, 压缩稀疏注意力]`
- **去重**：通过 `aliases` 处理同义概念，避免为同一概念创建多个文件

## 概念 vs 方向

- **概念**：技术术语、方法名、数学工具，从论文内容中**自动提取**。存放在 `_概念/` 下
- **方向**：用户定义的**研究兴趣分类**，在 Phase 1.4 手动选择。体现在目录结构中
- 两者不交叉——概念不按方向分子目录

## 已有概念更新示例

```
# 概念 Compressed Sparse Attention 已存在，被 DeepSeek-V4 引用

## 被引用
- [[arxiv2026-DeepSeek-V4]] — 作为混合注意力架构的核心组件，与 HCA 交替使用
```

如果后续 HumanEgo 也讨论了这个概念，追加：

```markdown
- [[arxiv2026-HumanEgo]] — 作为对比基线，HumanEgo 的 ICT 与 CSA 在压缩策略上形成对比
```
